# Подготовка 3D-моделей

Скрипты, которыми модели из Sketchfab готовились к загрузке в Roblox.
Сами модели в репозиторий не кладём: их нужно скачать с Sketchfab.

Модели:
- «[FREE] Store Props [Asset pack]», автор SimplePolygon. Это полки, холодильники, кассы и стеллажи склада.
- «Food Collection - Game Ready», автор Melon Polygons. Это продукты.

Обе работы под лицензией CC BY 4.0.

## Порядок

1. `split.py scene.gltf out 0` — разрезать сцену на отдельные GLB по одному мешу, без текстур. Центр каждой модели переносится в начало координат.
2. `uvmap.py scene.gltf textures uv` — найти, какой продукт какую область текстуры занимает. Результат — маски областей.
3. `clean.py <папка>` — закрасить на текстурах области, которые использует только пиво, вино или таблетки. Эти продукты в игру не загружаются.
4. `relabel.py <папка>` — заменить этикетки с упоминанием алкоголя своими: «Фасоль «Дачная»», «Тушёнка «Волга»».
5. Продукты, которые в исходной сцене стоят под углом, выровнять по прямоугольнику минимальной площади. Плоские продукты повернуть так, чтобы надпись читалась сверху.
6. Загрузить в Roblox:
   - Геометрию — как Model (`model/gltf-binary`).
   - Два продукта — вместе с текстурами. С них игра берёт PBR-материал (SurfaceAppearance).
   - Палитру полок — как Decal.
7. ID мешей записаны в `src/ReplicatedStorage/Shared/Models.lua`.

## Особенность импорта Roblox

Roblox разворачивает модель на 180° вокруг вертикали:

| В файле | В Roblox |
|---|---|
| +Z | −Z (LookVector) |
| +X | −X |

Поэтому:
- этикетки продуктов смотрят в LookVector детали;
- перёд полок и холодильников смотрит в локальную −X.
