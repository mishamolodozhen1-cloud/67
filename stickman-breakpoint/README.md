# STICKMAN: BREAKPOINT

Оригинальное аниме про стикменов: сверхъестественный экшен, приключения, комедия, драма и тайна.

- `docs/series_bible.md` — библия сериала: мир Нордена, система способностей «Изломы», персонажи, злодеи, организации, план сезонов.
- `docs/episode01_script.md` — подробный сценарий серии 1 «Обычный вторник» с таймкодами, которые совпадают с видео.
- `engine/` — процедурный движок анимации и сборка серии.

## Как собрать серию

```bash
pip install pycairo numpy scipy pillow     # плюс ffmpeg в системе
python3 engine/split_voice.py B0 B1 ...     # нарезка пакетной озвучки на реплики
python3 engine/batch_voice.py 24 <url>      # скачать пакет и нарезать его
python3 engine/single_voice.py b69=<url>    # одиночная реплика
python3 engine/cut_voice.py B24 k17=18.5:22.3   # ручная нарезка, если выравнивание ошиблось
python3 engine/render.py --scale 0.5 --fps 12 --out build/preview.mp4   # черновик
python3 engine/render.py                    # финал: 1920×1080, 60 fps, H.264 + AAC
python3 engine/make_script.py               # сценарий с фактическими таймкодами
```

Шрифты должны быть видны fontconfig (скопируйте `assets/fonts/*.ttf` в `~/.local/share/fonts` и выполните `fc-cache -f`). Субтитры набраны Inter из системного пакета `fonts-inter`.

## Устройство движка

| Модуль | Что делает |
|---|---|
| `gfx.py` | Небольшая прослойка со skia-подобным API поверх cairo |
| `core.py` | Кривые, дорожки ключей, камера (мультиплан + глубина резкости), шрифты, зерно, виньетка |
| `stickman.py` | Риг стикмена: позы, походка без проскальзывания, лица и эмоции, липсинк по огибающей голоса, аксессуары персонажей |
| `sets.py` | Локации Нордена по времени суток: панорама с институтом «Вертекс», мост, маяк, комната, кухня, класс, крыша, лестница, лаборатория |
| `props.py` | Реквизит и вставки: будильник, осколки телефона с «откатом», автобус, блокнот Миры, порванное фото |
| `fx.py` | Манга-эффекты: фокус-линии, звукоподражания, плашки персонажей, «давящие» буквы, трещина, метка точки останова, глитч |
| `film.py` | Рендер кадра: сортировка слоёв по глубине, размытие в пониженном разрешении, грейд, дуотон, субтитры |
| `director.py`, `stage.py` | Режиссёрский слой: реплики → звук + субтитр + липсинк, SFX, музыкальные cue, камера-«оператор». Реплика без озвучки автоматически становится манга-пузырём |
| `ep1_*.py`, `episode01.py` | Постановка серии 1 (`ep1_more.py` — сцены без слов: спор у дверей, Норден днём, журнал незнакомца, «тем временем») |
| `mix.py` | Сведение: обработка голосов (комната, зал, ТВ, шёпот), эмбиенты, SFX, музыка с даккингом под речь |
| `render.py` | Параллельный рендер в H.264, motion blur подкадрами, сведение со звуком, loudnorm −16 LUFS |

## Источники

- **Голоса:** ElevenLabs. Основная озвучка — `eleven_v4` с эмоциональными тегами; часть второстепенных реплик (мама, директор, Шнур, одна реплика Нильса) — `eleven_flash_v2_5`. Три реплики остались без голоса и показаны пузырём или бегущей строкой. Каст указан в `engine/lines.py`.
- **Музыка:** Soundza, AI-треки (Lyria — опенинг и эндинг, Stable — фоновые лупы).
- **Звуки:** Soundza, каталог и AI-генерация. Сердцебиение и звон в ушах синтезированы процедурно.
- Аудиофайлы не хранятся в репозитории: лицензия Soundza запрещает распространять звуки отдельно от произведения.
