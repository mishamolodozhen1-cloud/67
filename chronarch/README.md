# Стрела Судьбы — стенд «ХРОНАРХ»

Игра в Roblox: https://www.roblox.com/games/126350560275847

Оригинальный стенд в жанре «стенд-баттлер»: золотой бронированный **ХРОНАРХ, Повелитель Времени** с часами на груди и вращающимся нимбом-циферблатом.

## Что есть

- **Алтарь со Стрелой Судьбы** прямо перед точкой появления. Подойди и нажми «Взять стрелу» (на ПК клавиша F). Стрела срывается с алтаря и пронзает персонажа, после этого пробуждается стенд.
- **Барраж** (держать): шквал ударов с призрачными руками, шлейфами и свистом кулаков, в конце завершающий удар с отбрасыванием.
- **Остановка времени** на 5 секунд, перезарядка 20 секунд:
  - звук нарастает, звучит реплика стенда, мир становится серым;
  - все остальные игроки и манекены замирают;
  - стрелки часовой башни, огонь в жаровнях и пылинки в воздухе останавливаются;
  - урон по застывшим целям копится и прилетает разом, когда время снова пойдёт.
- **Управление под телефон**: крупные круглые кнопки дугой вокруг кнопки прыжка («Стенд», «Барраж», «Стоп»), полоска перезарядки внутри каждой кнопки.
- На ПК: Q — стенд, E (держать) — барраж, R — остановка времени. Геймпад: X / R2 / Y.
- **Манекены** с полосой здоровья для отработки ударов. После «смерти» они появляются снова.
- Мир: закатная площадь с мостовой и узором-розой ветров, дома с окнами, часовая башня, фонари, атмосфера и пост-эффекты.

## Структура

```
src/ReplicatedStorage/Shared/Config.lua        — баланс, звуки, цвета, смещения стенда
src/ServerScriptService/Main.server.lua        — точка входа сервера
src/ServerScriptService/WorldBuilder.lua       — карта, освещение, алтарь, манекены
src/ServerScriptService/ArrowBuilder.lua       — детализированная стрела (45 деталей)
src/ServerScriptService/StandBuilder.lua       — модель стенда (234 детали, 16 суставов)
src/ServerScriptService/StandService.lua       — урон, барраж, остановка времени
src/StarterPlayerScripts/StandClient/          — клиент: анимация, эффекты, кнопки
build.py                                       — сборка build/ArrowOfFate.rbxl
publish.sh                                     — сборка и публикация через Open Cloud
```

Сборка: `python3 build.py`. Публикация: `./publish.sh` (ключ берётся из `ROBLOX_API_KEY`).
Файл `build/ArrowOfFate.rbxl` можно открыть в Roblox Studio.

- Эффекты взяты с [Soundza](https://soundza.com) (лицензия Soundza Standard License):
  - Heavy Punch Hit, Swish 1, Movie Punch Hit;
  - Clock Tick with Reverb, Reversed Gong Horror Stinger, Dark Boom Impact;
  - Reverse Whoosh Sweep, Dark Magic Barrier, Low Whoosh Bamboo Swing;
  - Piercing Metal Impact, Crystalline Magic Spell Cast.

  Часть из них сведена между собой через ffmpeg.
- Реплика стенда «Хронарх… Время — моё!» сгенерирована в ElevenLabs.
- Все звуки загружены в Roblox как аудио-ассеты. Их ID лежат в `Config.lua`. Исходные файлы в репозиторий не кладутся: лицензия Soundza запрещает распространять их отдельно.
