# Казань — центр города (Roblox)

Игра: https://www.roblox.com/games/126350560275847

Исторический центр Казани по реальной карте OpenStreetMap в натуральную величину (1 стад = 0,3 м).
Участок около 1,8 × 3 км: от Кремля и улицы Баумана до Центра семьи «Казан» на другом берегу Казанки.

## Что есть в городе

- **Здания и улицы.** 3122 блока зданий и 2602 клиновидные детали для зданий сложной формы, всё по настоящим контурам и высотам из OSM. На фасадах окна, на крышах кровля, у старых домов двускатные крыши. Улицы, площади и пешеходные дорожки, разметка, фонари вдоль проспектов.
- **Казанка и канал Булак** сделаны водой рельефа. Парки и скверы покрыты травой, вокруг 1300 деревьев.
- **Кремль.** Белые стены с зубцами по реальной линии. Спасская, Тайницкая, Преображенская, Консисторская и угловые башни стоят на своих местах и имеют свою высоту.
- **Достопримечательности**, собранные вручную на своих местах:
  - мечеть Кул Шариф с бирюзовым куполом и четырьмя минаретами по 58 м;
  - падающая башня Сююмбике: семь ярусов красного кирпича, есть наклон;
  - Благовещенский собор;
  - Дворец земледельцев с бронзовым деревом в арке;
  - колокольня Богоявленского собора на улице Баумана (74 м);
  - Петропавловский собор;
  - Центр семьи «Казан» в виде чаши.
- **Президентский дворец** выкрашен в жёлтый цвет.

## Админ-панель

Кнопка 👑 слева на экране. Она видна только администраторам: UserId из `src/ReplicatedStorage/Shared/Settings.lua` и владельцу игры. Каждое действие сервер проверяет заново.

- **Я:**
  - полёт: на телефоне кнопки ▲▼, на ПК Пробел и Ctrl;
  - режим «сквозь стены», бессмертие, невидимость;
  - скорость ходьбы и полёта, сила прыжка;
  - лечение и перерождение.
- **Телепорт:** Спасская башня, Кул Шариф, Сююмбике, Благовещенский собор, Дворец земледельцев, колокольня, Петропавловский собор, Центр семьи «Казан», улица Баумана, Кремлёвская дамба, Кремлёвская набережная.
- **Мир:**
  - время суток: утро, день, закат, ночь;
  - туман и гравитация;
  - объявление для всех игроков (проходит фильтр текста Roblox).
- **Игроки:** «к нему», «ко мне», заморозить, кикнуть (с подтверждением).

## Как устроено

```
tools/merge_osm.py      — склейка выгрузок OSM API (тайлы + полные отношения рек)
tools/osm_to_luau.py    — перевод карты в данные для Roblox: здания раскладываются на блоки
                          (или клинья для сложных форм), Казанка и парки — полосы рельефа
src/ServerScriptService/CityData/  — сгенерированные данные (ODbL)
src/ServerScriptService/CityBuilder.lua — постройка рельефа, улиц, домов, стен, деревьев
src/ServerScriptService/Landmarks.lua   — достопримечательности
src/ServerScriptService/AdminService.lua — серверная часть админки
src/StarterPlayerScripts/KazanClient/   — заставка, объявления, админ-панель
build.py — сборка build/Kazan.rbxl
```

Город строится сервером при запуске (около 3–4 секунд). Чтобы играть на телефоне, включён стриминг: подгружается только то, что рядом с игроком.

## Данные карты
