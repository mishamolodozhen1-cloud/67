# StarterGui

- `MainUI` — главное меню лобби (PLAY, LOADOUT, SHOP, PROFILE, SETTINGS) — этап 8.
- `HUD` — прицел, здоровье, патроны, таблица игроков — этапы 4, 5, 11.
- `Menus` — окна поверх игры (настройки, магазин, профиль) — этапы 8, 10, 11.

Все три — ScreenGui с `ResetOnSpawn = false`: интерфейс не пересоздаётся после каждой смерти.
Наполнение появляется на своих этапах; на этапе 1 это только контейнеры.
