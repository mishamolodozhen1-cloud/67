# 🤖 Playerok Sales Bot

Telegram-бот для автоматизации продаж на **Playerok** (playerok.com) с плагином **Gmail аккаунты**.

## Возможности

- 🔑 **Подключение аккаунта Playerok по токену.** Меню открывается только после подключения. Сообщение с токеном бот удаляет сразу после проверки.
- 📥 **Загрузка товаров с аккаунта Playerok.** Бот показывает ваши лоты, вы выбираете нужный и подключаете к нему плагин. Дальше бот работает именно с этим лотом.
- 📧 **Плагин «Gmail аккаунты»**
  - загрузка текстом или `.txt` файлом в форматах `почта:пароль`, `почта:пароль:резерв`, `почта|пароль|резерв|доп`;
  - проверка формата, отсев не-Gmail адресов и дублей (в том числе тех, что уже есть на складе);
  - продажа **поштучно** или **пачкой**: вы указываете, сколько аккаунтов выдавать за одну оплату (1, 2, 5, 10… до 1000).
- 📝 **Универсальный плагин** для ключей, ссылок и любого текста: одна строка — одна единица товара.
- ⚡️ **Автовыдача.** После оплаты бот берёт товар со склада, отправляет его в чат сделки, отмечает сделку как «Отправлено» и присылает вам уведомление.
- 📦 **Склад:** просмотр (с маскировкой данных), выгрузка в `.txt`, очистка, предупреждение, когда товар заканчивается.
- 🔁 **Нехватка товара обрабатывается сама.** Если на складе не хватило, покупатель получает вежливое сообщение, а после пополнения склада бот выдаёт ожидающие заказы автоматически.
- ♻️ **Авто-восстановление лота** после продажи и ⏸ **авто-снятие лота**, когда склад пуст.
- 💲 Смена цены лота и кнопки «снять с продажи» / «выставить» прямо из бота.
- 💬 **Автоответчик:** приветствие новым покупателям, команда `!наличие`, правила по ключевым словам (по вхождению или точному совпадению).
- 🔔 **Уведомления** о сообщениях и продажах. Кнопка «✍️ Ответить» отправляет ваш ответ из Telegram прямо в чат Playerok.
- 🤝 Список сделок и ручная выдача, 📊 статистика, 💰 баланс.
- 🟢🔵 Все кнопки зелёные и синие (поле `style` из Bot API 9.4+).

## Запуск

Нужен Python 3.10+.

```bash
cd playerok_bot
pip install -r requirements.txt
python bot.py
```

Токен Telegram-бота уже прописан в `config.py`. Его можно переопределить переменной окружения `BOT_TOKEN`.

Необязательные переменные окружения:

| Переменная | Что делает |
|---|---|
| `OWNER_IDS` | Telegram ID через запятую, которым разрешён доступ. Если пусто, бот открыт всем, и каждый подключает свой Playerok |
| `DB_PATH` | путь к базе SQLite (по умолчанию `data/bot.db`) |
| `DEALS_POLL_INTERVAL` / `CHATS_POLL_INTERVAL` | период опроса сделок и чатов в секундах (12 / 8) |
| `PLAYEROK_PROXY` | прокси для запросов к Playerok |

> Бот должен работать постоянно (VPS, сервер, хостинг). Пока он выключен, автовыдачи нет. Сделки, оплаченные во время простоя, бот выдаст после запуска.

## Где взять токен Playerok

1. Откройте playerok.com в браузере на ПК и войдите в аккаунт.
2. Нажмите F12, откройте **Application**, затем **Cookies**, затем `https://playerok.com`.
3. Скопируйте значение cookie `token` и отправьте его боту.

## Как начать продавать

1. `/start`, затем **🔑 Подключить Playerok**, затем отправьте токен.
2. **📥 Загрузить с Playerok**, выберите лот и нажмите **📧 Подключить: Gmail аккаунты**.
3. **➕ Загрузить наличие**: отправьте аккаунты.
4. **🔢 За оплату**: выберите «Поштучно» или количество в пачке.
5. При желании настройте **✏️ Текст выдачи** (переменные `{buyer}`, `{item}`, `{qty}`, `{goods}`) и проверьте его кнопкой **🧪 Тест выдачи**.

Готово: бот сам выдаёт товар каждому, кто оплатит лот.

## Как это устроено

```
playerok_bot/
├── bot.py            запуск aiogram
├── config.py         настройки и токен
├── db.py             SQLite: пользователи, товары, склад, правила, сделки
├── engine.py         движок: автовыдача, автоответчик, уведомления
├── keyboards.py      зелёные и синие кнопки
├── states.py         FSM-состояния
├── plugins/          gmail.py, text.py — формат склада и выдачи
└── handlers/         start, items, products, autoresponder, deals, settings
```

Работа с Playerok идёт через библиотеку [PlayerokAPI](https://pypi.org/project/PlayerokAPI/). События приходят по WebSocket, а параллельно бот опрашивает сделки и чаты, чтобы ничего не пропустить. Повторы отсекаются по id, поэтому один заказ не выдаётся дважды.

Сделки, оплаченные **до** подключения токена, бот автоматически не трогает. Их можно выдать вручную в разделе «🤝 Сделки».
